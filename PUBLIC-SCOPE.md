# Public selection boundary

This repository is an allowlisted selection, not a mirror of a working toolkit.

This repository contains only:

- File Tree Scaffold Generator, including its Research Project Starter tab,
  lightweight planning templates and deterministic content-ZIP writer.
- Cytoscape Import Table Builder, including its Table Match Checker tab and
  minimal UTF-8/CSV helpers.
- Their documentation, browser navigation and automated checks.

Analysis workflow source and synthetic workflow examples belong in
[Research Workflows](https://github.com/septemberkk/research-workflow-public).
The legacy evidence-mapping directory contains a source link only.

MIT licensing is unchanged. The npm package remains `private: true` to prevent
accidental npm publication; this is separate from GitHub repository visibility.

Scientific Palette Explorer, its preset collections and shared category-colour
mapping modules; Enrichment Mapping Reviewer; the full project-governance package;
private toolkit placeholders; and other research repositories are not included.

Only synthetic examples and generic planning templates belong here. Never add
actual research data/results, reviewer sessions/notes, report downloads containing
identifiers, browser QA outputs, local handoffs, attachment images, machine paths,
credentials or an entire private-repository history. Public frontend code is
inspectable when delivered by a website, independently of GitHub visibility.
