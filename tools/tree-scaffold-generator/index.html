File Tree Scaffold Generator

Turn a pasted file tree into an empty folder-and-file scaffold. Preview the paths first, then download a ZIP.

Your text stays in this browser. The page does not upload or save it.

Use a root folder ending in /, then standard ├── and └── branches. Folder leaves should end in /.

Preview the example or paste your own tree.
