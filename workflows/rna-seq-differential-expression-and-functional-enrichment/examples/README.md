# Synthetic example

The example contains 56 artificial features and six artificial samples, with
three samples in each group. A is the reference group and B is the comparison.
The counts are hand-constructed and do not represent a biological study.

| Features | Pattern |
| --- | --- |
| GENE_001–004 | Larger counts in group B |
| GENE_005–008 | Larger counts in group A |
| GENE_009–048 | Similar group-level counts with within-group variation |
| GENE_049–053 | Zeros, low counts and the mean-count boundary |
| GENE_054–056 | Values close to the filtering threshold |

Identifiers have no biological meaning and are not suitable for annotation or
pathway analysis. The count patterns do not guarantee a particular number of
significant genes.
